Privacy Policy

App: 4Zones (Shizuku Edition) • Effective Date: August 21, 2026

This page is the single authoritative 4Zones privacy policy. It explains how 4Zones handles information when you install and use the app.

1. Nothing is transmitted

4Zones holds no network permission, so it has no channel to send anything off your device, and there is no 4Zones server for anything to be sent to. You can check this in the app's manifest, which declares no network permission of any kind.

2. One setting is saved

4Zones saves one setting: the time you accepted the in-app accessibility disclosure, kept in the app's own private preferences.

3. Everything else stays in memory

Everything else 4Zones keeps while it is running is held in memory and discarded when the app's process ends. It can include window details such as app package names, display and task identifiers, and timestamps.

4. Components

4Zones performs privileged window operations through Shizuku, a separate app you install yourself, over local inter-process communication on your device. Every third-party component packaged into the released app is listed, with its licence, in the THIRD_PARTY_NOTICES.md file at the root of the 4Zones source repository.
